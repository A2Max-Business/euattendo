titulo: Conexões MCP administrativas carregam o catálogo de ferramentas
---
Corrigida a descoberta das ferramentas MCP quando a conexão possui permissões de configuração. As condições das automações continuam exigindo somente um combinador por grupo, agora com um contrato compatível com JSON Schema. A autenticação e as permissões existentes são preservadas.
